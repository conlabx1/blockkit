# input

## 하는 일
프로그램의 표준 입력에서 한 줄을 읽어 온다.

## 입력
- 없음. 읽는 곳은 프로그램의 표준 입력(키보드로 친 글자나 앞 프로그램이 넘겨준 글자)이다.

## 출력
- 읽은 한 줄(글자). 줄 끝의 줄바꿈은 떼고 돌려준다. 빈 줄을 읽었으면 빈 글자를 돌려준다.
- 오류로 끝났을 때는 입력을 어디까지 읽었는지 정해져 있지 않다. 오류가 난 뒤에 이어서 읽으면 긴 줄의 남은 부분이 새 줄처럼 읽힐 수 있다.

## 금지 사항
- [N1] 입력이 끝나서 읽을 것이 없으면 빈 글자를 돌려주지 않는다. 오류로 알린다.
- [N2] 1,000바이트를 넘는 줄은 받지 않는다. 끝없이 긴 입력이 메모리를 다 쓰면 안 되기 때문이다.
