# greet

## 하는 일
이름을 받아 인사말 한 줄을 만든다. 이름을 받지 못했으면 한 번 물어서 받는다.

## 입력
- 이름(글자). 앞뒤 공백은 떼고 쓴다.
- 이름을 묻는 방법(조립이 넘겨주는 함수). 받은 이름이 비어 있을 때만 쓴다.

## 출력
- 「○○님, 안녕하세요.」 형태의 인사말 한 줄.

## 금지 사항
- [N1] 빈 이름으로는 인사말을 만들지 않는다. 오류로 알린다.
- [N2] 줄바꿈이 든 이름은 받지 않는다. 인사말이 여러 줄로 깨지면 안 되기 때문이다.
- [N3] 이름을 이미 받았으면 다시 묻지 않는다.
